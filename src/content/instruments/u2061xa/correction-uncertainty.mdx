Power sensor의 `SENS:FREQ 3.5GHZ`는 spectrum analyzer처럼 3.5 GHz만 골라 받는 tuning command가 아니다. 이미 입력된 broadband RF power에 **어느 주파수의 sensor response와 external path correction을 적용할지** 알려 주는 조건이다.

<LessonLayer level="intuition" title="숫자를 고치는 단계와 기준면을 옮기는 단계를 분리하자">

## Zero, calibration, frequency와 path correction은 서로 다른 질문에 답한다

1. **Zero** — RF가 없을 때 detector offset은 얼마인가?
2. **Calibration** — 내부 reference로 detector conversion은 올바른가?
3. **Measurement frequency** — 이 carrier에 해당하는 sensor frequency response correction은 무엇인가?
4. **Path correction** — Sensor connector와 DUT plane 사이 loss/gain은 얼마인가?
5. **Mismatch uncertainty** — Source와 sensor가 50 Ω에서 벗어나 생기는 불확실성은 얼마인가?

이 중 하나를 했다고 나머지가 자동으로 해결되지는 않는다.

<Definition term="Frequency-dependent offset" symbol="FDO">
Cable, coupler, attenuator 같은 외부 test path의 주파수별 loss/gain을 보정하는 table이다. U2061XA 계열은 10개 FDO table, 각 512 frequency point를 지원한다. Sensor 자체 frequency response correction에 추가된다.
</Definition>

<Definition term="Gamma correction">
Source reflection coefficient의 magnitude와 phase를 사용해 mismatch effect를 보정하는 기능이다. Single-point gamma와 table-based correction은 적용 범위와 상호 배타 조건을 확인해야 한다.
</Definition>

<InstrumentLab labId="sensor-correction" />

## Correction을 적용해도 uncertainty는 사라지지 않는다

VNA로 cable S-parameter를 측정해 sensor에 넣으면 nominal insertion loss를 더 잘 보정할 수 있다. 그러나 VNA calibration uncertainty, cable movement, connector repeatability, temperature와 DUT/sensor mismatch가 남는다. Correction은 중앙값을 이동하고 uncertainty budget은 그 결과가 가질 수 있는 범위를 설명한다.

</LessonLayer>

## 권장 zero·calibration 경계

Keysight programming guide는 다음 조건에서 zero/calibration을 권장한다.

- Sensor connection을 새로 확립했을 때
- 온도가 5 °C 변했을 때
- 24시간마다
- Low-level signal을 측정하기 전
- Measurement speed mode가 바뀌었을 때

Internal zero는 RF path를 내부적으로 전환하므로 DUT와의 물리 연결을 유지할 수 있다. 그래도 PA bench의 안전 sequence에서는 SG RF OFF를 확인한 뒤 실행하면 source 상태와 zero 조건을 명확하게 기록할 수 있다. External zero는 RF가 없는 상태가 필수다.

~~~text
*IDN?
SYST:ERR?
*CLS
CAL:ZERO:TYPE INT
CAL:ALL?
SYST:ERR?
SENS:FREQ 3.5GHZ
SENS:FREQ?
READ?
SYST:ERR?
~~~

`CAL:ALL?` response `0`은 pass, `1`은 fail이다. Query response와 error queue를 둘 다 읽는다.

<MeasurementNote title="Preset이 correction table과 zero data를 모두 지운다고 가정하지 않는다" kind="condition">
User's Guide는 preset이 FDO, gamma, S-parameter table, selected correction table과 zero/calibration data에 영향을 주지 않는다고 설명한다. 자동화는 `*RST`나 preset으로 출발했다는 이유만으로 correction state가 원하는 값이라고 가정하지 말고 query-back한다.
</MeasurementNote>

## DUT plane으로 되돌리는 correction 순서

| 순서 | 값 | 역할 |
|---|---|---|
| 1 | Raw detector result | Sensor connector에서 측정한 power |
| 2 | Sensor frequency response | `SENS:FREQ`가 선택한 내부 correction |
| 3 | Fixed channel gain/loss | 한 주파수 또는 좁은 band의 단순 offset |
| 4 | FDO | 주파수별 external path loss |
| 5 | Gamma/S-parameter | Source/path mismatch와 2-port network 보정 |
| 6 | DUT-plane result | 정의한 reference plane의 중앙값 |

Fixed offset과 FDO, host-side path correction을 모두 같은 cable loss에 적용하면 중복 보정이다. Test record에는 correction 이름, source file, calibration date, plane과 enabled state를 함께 저장한다.

## U2061XA SWR를 power level과 함께 사용한다

10 MHz~6 GHz에서 공식 최대 SWR은:

- Sensor power `−70~+15 dBm`: `1.15`
- Sensor power `+15~+26 dBm`: `1.24`

한 개의 고정 SWR만 사용하지 말고 실제 sensor connector power 구간에 맞춰 선택한다. DUT source SWR도 같은 주파수와 operating state에서 얻는다.

</LessonLayer>

<LessonLayer level="theory" title="Reference-plane correction과 uncertainty 결합을 수식으로 닫자">

<FormulaDisclosure title="DUT-plane power" formula="P_DUT(dBm) = P_sensor(dBm) + C_path(dB)">
Sensor까지 30.7 dB attenuation이 있다면 `Cpath=+30.7 dB`다. 이 값은 DUT-plane 표시를 위한 correction이며 sensor connector damage 판단에는 더하지 않는다.
</FormulaDisclosure>

<FormulaDisclosure title="SWR에서 reflection coefficient" formula="|Γ| = (SWR−1)/(SWR+1)">
SWR 1.15이면 `|Γ|≈0.0698`, SWR 1.50이면 `|Γ|=0.2`다.
</FormulaDisclosure>

<FormulaDisclosure title="Keysight Appendix의 standard mismatch term" formula="u_mismatch = |Γ_DUT|·|Γ_sensor|/√2">
두 reflection magnitude를 주어진 estimate로 두고 unknown relative phase가 만드는 U-shaped distribution에 `√2` divisor를 적용한 standard relative uncertainty다. Worst-case mismatch limit와 같은 값이 아니다.
</FormulaDisclosure>

<FormulaDisclosure title="RSS와 expanded uncertainty" formula="u_c = √(u_system² + u_mismatch²);   U = k·u_c">
각 항이 standard uncertainty인지 expanded uncertainty인지 먼저 통일한다. Lab은 다른 모든 표준 성분을 한 항으로 받고 mismatch standard term과 RSS한 뒤 `k=2`를 적용한다.
</FormulaDisclosure>

## Basic accuracy를 total uncertainty로 복사하지 않는다

U2061XA average measurement의 basic accuracy는 특정 power, DUT SWR, averaging과 free-run 조건에 대한 값이다. 실제 결과는 다음을 조건별로 합친다.

- Zero set과 zero drift
- Measurement noise와 aperture/averaging
- Sensor calibration uncertainty
- External path characterization uncertainty
- Connector repeatability와 temperature
- DUT와 sensor mismatch
- Trigger/gate repeatability
