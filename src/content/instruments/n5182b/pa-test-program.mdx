PA 시험 프로그램은 `for power in levels` loop가 아니다. Source, bias, DUT temperature, output protection, analyzer range와 trigger가 모두 유효한 상태에서만 한 measurement point를 만들 수 있다. 실패했을 때 어느 state까지 되돌릴지도 정상 sequence만큼 중요하다.

<LessonLayer level="intuition" title="한 측정점을 여러 장비가 함께 만드는 transaction으로 보자">

## 한 점의 gain에는 최소 세 개의 서로 다른 전력이 있다

- **MXG setpoint** — generator connector에서 목표로 하는 출력
- **DUT input power** — cable·coupler·attenuator와 mismatch 이후 PA가 실제로 받은 drive
- **DUT output power** — output path correction 이후 PA output plane의 power

Gain을 계산할 때 MXG setpoint를 그대로 `Pin`으로 쓰면 input path loss가 gain에 섞인다. Program은 각 값의 reference plane과 correction source를 type과 log에 포함해야 한다.

<Definition term="Test point transaction">
한 stimulus 조건을 설정하고, settle을 기다리고, 필요한 측정값과 instrument state를 함께 읽고, validation을 통과한 뒤에만 결과 한 행을 commit하는 단위다. 중간 실패값은 정상 result와 분리해 diagnostic record로 남긴다.
</Definition>

<Definition term="Abort path">
Over-current, over-temperature, analyzer overload, 통신 timeout 또는 사용자 stop에서 실행하는 안전 전이 경로다. 일반적으로 RF Off가 가장 먼저 오지만 DUT별 bias sequence와 보호 회로 요구사항을 별도 safety specification으로 따라야 한다.
</Definition>

<InstrumentLab labId="mxg-pa-test-program" />

## 정상 경로와 실패 경로를 함께 그린다

`Preflight → Safe outputs → Bias ramp → Source configure → RF enable → Settle → Acquire → Validate → Commit → Next point`

어느 상태에서도 실패하면:

`RF Off → analyzer/source safe range → DUT-specific bias safe-down → error/status capture → session close 또는 controlled recovery`

Recovery 후 같은 point를 무조건 반복하지 않는다. 실패 원인이 DUT damage, thermal limit 또는 calibration invalidation일 수 있기 때문이다.

</LessonLayer>

## 0. Test plan을 장비 command보다 먼저 정의한다

각 시험은 최소한 다음 contract를 가진다.

| 항목 | 예 |
|---|---|
| DUT identity | Serial, revision, fixture, connector torque record |
| Bias | Voltage/current limit, ramp, enable/disable order, settle condition |
| Stimulus | CW/waveform ID, frequency, target Pin, trigger, duration |
| Input plane | Source correction과 검증 sensor 위치 |
| Output plane | Coupler/attenuator/cable correction과 analyzer 위치 |
| Stop condition | Current, temperature, Pout, compression, reflected power limit |
| Measurement | Pin, Pout, phase, current, voltage, EVM, ACLR 등 |
| Cleanup | RF Off, waveform/Mod state, bias safe-down, error collection |

## 1. Preflight는 RF가 꺼진 상태에서만 통과시킨다

- 모든 장비 `*IDN?`과 필요한 option을 확인한다.
- Calibration artifact의 ID, timestamp, frequency range와 plane을 확인한다.
- MXG RF/Mod/ARB를 Off로 query-back한다.
- Analyzer attenuation, reference level과 maximum safe input을 설정한다.
- Power supply output을 안전 상태로 확인하고 current limit을 설정한다.
- Temperature, interlock, fan/fixture cooling과 emergency stop을 확인한다.
- PA output이 source 쪽으로 돌아갈 가능성과 coupler/isolator 방향을 확인한다.

<MeasurementNote title="Bias sequence는 Wiki의 일반 순서보다 DUT safety specification이 우선한다" kind="warning">
Gate/drain 순서, negative gate 유지, current limit, discharge time과 thermal interlock은 PA technology와 module 회로에 따라 다르다. 자동화 코드에 임의의 공통 bias 순서를 하드코딩하지 말고 승인된 DUT별 policy를 주입한다.
</MeasurementNote>

## 2. DUT input calibration을 별도 단계로 만든다

PA를 제거하거나 안전한 through/calibration path를 사용해 MXG setpoint와 DUT input plane power의 관계를 측정한다.

1. Frequency grid와 낮은 source level을 정한다.
2. DUT input plane에 calibrated sensor/receiver를 둔다.
3. 각 frequency에서 여러 level을 측정해 linearity를 확인한다.
4. `correction(f, level)`과 uncertainty를 저장한다.
5. Cable을 다시 연결했으면 connector repeatability를 uncertainty에 포함한다.
6. Calibration checksum/ID를 test result에 연결한다.

Source correction은 무한정 extrapolate하지 않는다. Frequency, level과 path configuration 범위를 벗어나면 preflight에서 거절한다.

## 2.5. 저전력 safe bring-up은 모든 recipe의 공통 입구다

1. RF Off에서 DUT별 bias sequence를 적용하고 current·temperature가 정상인지 확인한다.
2. 충분한 external attenuation을 둔 채 MXG를 최저 검증 drive로 설정한다.
3. Frequency·power·RF Off를 query-back하고 analyzer/sensor가 overload되지 않을 range를 확인한다.
4. RF On 뒤 DUT plane Pin, Pout, current와 spectrum에 예상하지 않은 oscillation이 없는지 읽는다.
5. 한 번에 큰 jump를 하지 않고 승인된 step·dwell로 목표 시험 시작점까지 올린다.
6. 첫 point가 불일치하면 correction으로 숨기지 않고 source path, DUT bias와 measurement range를 다시 분리한다.

## 3. CW small-signal gain과 frequency response

낮은 drive에서 PA가 linear한지 확인한 뒤 frequency를 sweep한다.

~~~text
for each frequency:
    RF OFF
    set frequency
    set low safe power
    query-back + error check
    RF ON
    wait source/DUT/analyzer settling
    measure calibrated Pin and Pout
    validate overload/current/temperature
    commit gain = Pout - Pin
RF OFF
~~~

Fast sweep가 목적이어도 먼저 stepped, fully-verified baseline을 만든다. List sweep 최적화는 동일한 결과를 내는지 비교한 뒤 적용한다.

## 4. Gain compression과 P1dB

Frequency를 고정하고 Pin을 작은 step으로 올린다. 각 point에서 linear extrapolation gain과 실제 gain 차이를 계산한다.

- 시작 level은 충분히 linear하고 noise보다 높게 잡는다.
- 큰 step으로 P1dB를 건너뛰지 않도록 coarse→fine search를 사용한다.
- Current, temperature, reflected power와 Pout limit을 각 point에서 검사한다.
- PA가 thermal memory를 보이면 sweep direction·dwell과 cooldown을 기록한다.
- Source·analyzer 자체 compression이 아닌지 through/level audit으로 확인한다.

P1dB 이후 Pout 증가량이 계속 줄어드는 영역에서 Psat를 찾을 수 있지만, “더 이상 늘지 않을 때까지 무조건 밀기”가 recipe가 되어서는 안 된다. DUT absolute maximum, current, temperature, reflected power와 analyzer input 한계 중 하나라도 먼저 도달하면 그 지점이 시험 stop이다.

**Source compression과 DUT compression을 분리하는 방법:** PA를 제거한 calibrated through path에서 같은 MXG setpoint sweep를 수행해 실제 Pin 증가량을 본다. MXG setpoint는 1 dB 늘었는데 measured Pin이 1 dB 늘지 않으면 DUT가 아니라 source/path가 먼저 비선형이 된 것이다. DUT 시험에서는 `ΔPout/ΔPin`을 measured plane 값으로 계산한다.

## 5. Modulated EVM·ACLR·SEM 시험

Golden waveform을 checksum으로 고정하고 다음 값을 함께 저장한다.

`waveform ID · sample rate · runtime scaling · RF frequency · target/actual Pin · trigger · analyzer demod configuration · equalization/reference · EVM normalization · ACLR integration bandwidth · SEM mask/version`

권장 관찰 순서는 다음과 같다.

1. Low drive through path에서 waveform과 analyzer setup의 baseline EVM/ACLR/SEM을 만든다.
2. PA low drive에서 linear baseline을 만든다.
3. Pin을 올리며 Pout, gain, EVM, ACLR, SEM margin, current와 temperature를 같은 point에 저장한다.
4. IQ capture가 가능하면 AM-AM, AM-PM과 spectrum regrowth를 연결한다.
5. Waveform 변경 또는 analyzer reconfiguration 뒤에는 새 baseline을 만든다.

EVM, ACLR 또는 SEM margin이 나빠졌다는 이유만으로 PA를 결론 내리지 않는다. MXG clipping/runtime scaling, source modulation quality, analyzer range, reference signal/equalization, mask·bandwidth 설정과 synchronization을 먼저 분리한다.

## 5.1. DPD 전후와 burst·thermal droop recipe

- **DPD A/B:** 같은 waveform, sample rate, target Pin, reference plane과 analyzer equalization을 고정한다. DPD coefficient/version과 training capture를 artifact로 저장하고, DPD Off/On의 AM-AM·AM-PM, EVM, ACLR와 PAE를 같은 thermal 상태에서 비교한다.
- **Burst droop:** Marker/trigger로 burst 시작을 맞추고 envelope power, gain, phase와 supply current를 시간축으로 함께 캡처한다. 첫 symbol과 burst 말단 차이는 PA thermal/electrical memory일 수도 있지만 MXG ALC settling, trigger delay 또는 analyzer time alignment를 먼저 baseline에서 분리한다.
- **Duty-cycle sweep:** Average input이 같아도 duty cycle이 바뀌면 junction temperature와 supply droop가 달라진다. Pulse width, period, on-time average/peak, cooldown과 fixture temperature를 함께 기록한다.
- **Long-run thermal:** 반복 waveform이 너무 짧으면 실제 traffic statistics를 대표하지 못할 수 있다. Record length와 repetition 조건을 test contract에 포함하고 온도 안정 전후를 구분한다.

## 6. 한 point를 commit하는 data shape

~~~python
from dataclasses import dataclass


@dataclass(frozen=True)
class PaPoint:
    frequency_hz: float
    target_pin_dbm: float
    measured_pin_dbm: float
    measured_pout_dbm: float
    supply_voltage_v: float
    supply_current_a: float
    temperature_c: float
    evm_percent: float | None
    aclr_lower_dbc: float | None
    aclr_upper_dbc: float | None
    sem_margin_db: float | None
    waveform_sha256: str | None
    calibration_id: str
    valid: bool
    invalid_reason: str | None
~~~

실제 API에서는 단위가 있는 branded type 또는 field name을 유지한다. `power=30`처럼 reference와 unit가 없는 bare number를 장비 경계로 넘기지 않는다.

## 7. State-machine skeleton

~~~python
def run_point(station, request):
    station.assert_preflight(request)
    station.mxg.output_off()
    try:
        station.dut.apply_bias(request.bias_policy)
        station.mxg.configure_stimulus(request.stimulus)
        station.assert_source_state(request.stimulus)
        station.mxg.output_on(request.enable_permit)
        station.wait_until_settled(request.settling_policy)

        raw = station.acquire_all()
        station.assert_limits(raw, request.stop_limits)
        corrected = station.apply_calibration(raw, request.calibration_id)
        return station.validate_and_commit(corrected)
    finally:
        station.mxg.output_off()
        station.dut.safe_down(request.bias_policy)
        station.capture_diagnostics()
~~~

이 skeleton의 `finally`는 핵심 의도를 보여 주지만 production safety를 완성하지 않는다. Cleanup command별 실패, process kill, network loss와 hardware interlock을 별도 설계해야 한다.

## 실무 팁

- Source setpoint, query-back, calibrated Pin을 모두 저장하되 서로 덮어쓰지 않는다.
- Measurement point 순서를 randomize할지 결정할 때 thermal drift와 hysteresis를 고려한다.
- Retry는 measurement timeout과 safety-limit violation을 구분한다. Safety violation은 자동 retry하지 않는다.
- Analyzer overload와 under-range를 measurement 값으로 저장하지 않고 invalid reason으로 분리한다.
- 정상 결과만 CSV 한 행으로 남기지 말고 station configuration snapshot과 error/status log를 연결한다.
- Test 종료 뒤 RF Off와 bias safe-down을 다시 query하거나 독립 hardware state로 확인한다.

<LessonLayer level="theory" title="Gain·compression·PAE·EVM의 분모와 기준면을 고정하자">

<FormulaDisclosure title="Power gain" formula="G_P(dB) = P_out,DUT-plane(dBm) − P_in,DUT-plane(dBm)">
두 power는 같은 waveform condition과 명시된 input/output reference plane에서 측정한다. MXG connector setpoint를 DUT-plane Pin 대신 쓰지 않는다.
</FormulaDisclosure>

<FormulaDisclosure title="1 dB compression" formula="G_linear(P_in) − G_actual(P_in) = 1 dB">
`G_linear`는 충분히 낮은 drive의 linear fit 또는 baseline gain이다. Noise-dominated point나 이미 compressed된 point로 fit하지 않는다. Interpolation 방식과 power step을 결과와 함께 기록한다.
</FormulaDisclosure>

<FormulaDisclosure title="Power-added efficiency" formula="PAE = (P_RF,out − P_RF,in) / P_DC × 100%">
RF power는 watt로 변환해 빼고, `P_DC`는 관련 supply rail의 voltage×current를 같은 steady-state 또는 averaging condition에서 합산한다. Pulsed signal은 time alignment와 duty-cycle convention을 명시한다.
</FormulaDisclosure>

<FormulaDisclosure title="EVM" formula="EVM_rms = √(Σ|S_meas−S_ref|² / Σ|S_ref|²) × 100%">
Reference symbol, equalization, timing, carrier recovery, averaging과 normalization이 결과를 바꾼다. Analyzer setup snapshot 없이 EVM 숫자만 비교하지 않는다.
</FormulaDisclosure>

## Cause/Effect를 시험 전체로 설명하기

“Target Pin을 1 dB 올리자 MXG source level이 증가했고 DUT-plane calibration으로 실제 Pin을 다시 측정했다. Pout 증가는 1 dB보다 작아져 gain compression이 커졌고, 동시에 current·EVM·ACLR을 같은 point에서 수집했다. Analyzer range와 DUT temperature가 유효한 점만 commit했으며 limit 초과 시 RF Off→DUT-specific bias safe-down 경로로 전이했다.”

## 이 프로그램이 아직 보장하지 않는 것

- Hardware interlock, fixture arc/over-temperature와 DUT-specific bias safety
- Sensor/analyzer calibration과 전체 uncertainty budget
- Harmonic, pulsed, load-pull 또는 multi-tone 시험의 추가 synchronization
- N5182B와 analyzer의 residual EVM/ACLR가 DUT 요구보다 충분히 좋은지 여부
- Compliance 판정에 필요한 표준별 waveform·filter·limit procedure

따라서 이 장은 production test software의 학습 구조이며 장비 제조사와 DUT safety specification을 대체하지 않는다.
