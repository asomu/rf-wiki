VNA가 “open”을 측정했는데 완벽한 `Γ=+1`이 나오지 않는 이유는 DUT가 없어서가 아니라 test set, cable, connector와 receiver 경로가 측정에 이미 들어 있기 때문이다. Calibration은 이 오차를 무시하는 zeroing이 아니라, 알려진 표준을 측정해 complex systematic error model을 추정하는 과정이다.

<LessonLayer level="intuition" title="Calibration을 cable 끝까지의 오차 지도를 만드는 일로 보자">

## 측정기가 자기 자신을 완벽히 보지 못하는 다섯 이유

- **Directivity**: 반사 경로 분리가 완벽하지 않아 incident wave 일부가 reflection receiver에 샌다.
- **Source match**: source port mismatch와 DUT reflection이 다시 반사되어 incident 조건을 바꾼다.
- **Load match**: response port mismatch가 transmission/reflection ratio에 되먹임된다.
- **Reflection tracking**: reference와 reflection receiver의 amplitude·phase 경로가 다르다.
- **Transmission tracking**: reference와 transmission receiver의 경로 차이가 S21/S12에 남는다.

<Definition term="Calibration reference plane">
Calibration 표준의 electrical behavior가 정의되고 correction이 끝나는 위치다. Cable 끝에서 calibration하면 그 connector face가 새 plane이다. 그 뒤 추가한 adapter·fixture는 DUT의 일부처럼 측정된다.
</Definition>

<Definition term="CalSet">
Calibration error terms, stimulus 조건과 관련 metadata를 저장한 correction artifact다. “Cal Done”이라는 표시만으로 connector, kit, frequency, power와 cable 상태가 맞는지는 증명되지 않는다.
</Definition>

## SOLT와 ECal은 목적은 같지만 표준을 제시하는 방법이 다르다

- **Mechanical SOLT**: Open, Short, Load와 Through를 사람이 순서대로 연결한다. Kit definition, connector gender, torque와 표준 상태가 핵심이다.
- **ECal**: 내부의 알려진 impedance states를 전환해 여러 standard state를 자동 측정한다. 연결 반복은 줄지만 ECal model·connector·frequency range와 characterization validity를 확인해야 한다.

N4691D의 일반 3.5 mm 2-port 범위는 300 kHz–26.5 GHz이고 Option 0DC는 DC capability가 추가된다. E5080B-2K0의 9 kHz 시작 주파수 전체를 N4691D 기본 범위가 자동으로 덮는다고 쓰지 않는다.

</LessonLayer>

<LessonLayer level="bench" title="Guided calibration을 connection·power·step·save 상태기계로 실행하자">

## 시작 전 contract

| 항목 | 기록할 값 |
|---|---|
| Analyzer | Model, serial, firmware, option, warm-up |
| Stimulus | Start/stop, points/type, IFBW, source power |
| Ports | Port 수, cable ID, connector type/gender, adapter |
| Standard | Cal kit/ECal model·serial·characterization ID |
| Method | SOLT, ECal, response, TRL 등 |
| Plane | 어느 connector face에서 DUT를 정의하는가 |
| Safety | Normal/cal power limit와 active DUT reverse path |

<MeasurementNote title="SCPI guided calibration 전 calibration power limit을 별도로 켠다" kind="warning">
`SYST:POW1:LIM:CAL -20 DBM`처럼 cal standard와 DUT에 맞는 limit을 설정하고 `SYST:POW:LIM:CAL:STAT ON`을 확인한다. SCPI calibration에서는 이 state가 자동 적용된다고 가정하지 않는다. `finally`에서 OFF로 정리하고 일반 source limit은 별도로 유지한다.
</MeasurementNote>

## Guided SCPI 흐름을 의미 단위로 나눈다

정확한 connector/kit argument는 설치 장비와 online help의 GUID command description에서 확인한다. 이 Wiki는 명령을 외우는 대신 순서를 고정한다.

~~~text
OUTP OFF
*IDN?
*OPT?
SYST:POW1:LIM:CAL -20 DBM
SYST:POW:LIM:CAL:STAT ON

# SENS1:CORR:COLL:GUID:CONN:PORT...  connector 지정
# SENS1:CORR:COLL:GUID:CKIT:PORT...  kit 지정
# SENS1:CORR:COLL:GUID:INIT          guided cal 초기화
# ...:STEP? / ...:DESC?              필요한 standard 확인
# ...:ACQ STANn                      현재 standard 측정
# SENS1:CORR:COLL:GUID:SAVE          error terms 저장
*OPC?
SENS1:CORR:STAT?
SYST:ERR?

SYST:POW:LIM:CAL:STAT OFF
OUTP OFF
~~~

실제 command spelling과 port-specific suffix는 E5080B firmware A.20.25.03 online help를 기준으로 한다. 다른 analyzer family의 calibration command를 섞지 않는다.

## Standard를 연결할 때 매번 확인한다

1. RF OFF와 port source state를 확인한다.
2. Connector를 inspect하고 particle·pin damage가 없을 때만 clean한다.
3. Gender와 cal kit definition이 guided step과 맞는지 확인한다.
4. Finger-tight 뒤 지정 torque wrench로 체결한다.
5. Cable을 지지하고 calibration 이후 굽힘을 최소화한다.
6. `*OPC?`, step completion과 error queue를 확인한 뒤 다음 standard로 간다.

## Calibration 뒤 조건 변경을 네 상태로 기록한다

- **Valid**: frequency grid, power, IFBW, sweep mode와 cable state가 calibration 조건과 일치한다.
- **Interpolated**: original range 안에서 point/grid를 바꾸고 analyzer가 correction terms를 보간한다. Valid와 같은 증거가 아니다.
- **Questionable**: power, IFBW, sweep mode, connector/cable 상태 또는 fixture가 달라졌다.
- **Outside range / correction off**: original calibration range 밖으로 sweep를 확장했다.

“C*” 또는 interpolation indication을 보았다고 자동 통과시키지 않는다. Verification standard나 known through/load를 다시 측정해 residual error를 확인한다.

## Calibration verification을 별도 측정으로 남긴다

- 50 Ω verification load의 S11을 측정한다.
- Known through/airline의 S21 magnitude·phase를 측정한다.
- Cable flex 전후 trace를 비교한다.
- Open/short를 calibration에 쓴 같은 standard로만 검증하지 않는다.
- Verification result, limit, timestamp와 screenshot/data를 CalSet ID에 연결한다.

<LessonLayer level="theory" title="Error model과 reference plane 이동을 복소수로 이해하자">

<FormulaDisclosure title="1-port error model의 직관" formula="Γ_meas = E_D + (E_R·Γ_DUT)/(1 − E_S·Γ_DUT)">
`E_D`는 directivity, `E_R`은 reflection tracking, `E_S`는 source match error다. Open/short/load처럼 알려진 서로 다른 Γ를 측정하면 세 unknown complex error term을 풀 수 있다.
</FormulaDisclosure>

<FormulaDisclosure title="Corrected DUT reflection" formula="Γ_DUT = f⁻¹(Γ_meas, E_D, E_R, E_S)">
Correction은 measured value와 error terms의 complex 역연산이다. 표준 정의가 틀리거나 cable이 움직여 error terms가 바뀌면 정밀한 수학이 오히려 정밀한 잘못된 답을 만든다.
</FormulaDisclosure>

## Calibration이 제거하지 못하는 것

- Random receiver noise와 drift
- Connector repeatability와 calibration 이후 cable flex
- Cal standard characterization uncertainty
- Calibration plane 뒤 fixture의 error
- DUT의 time variance, heating와 compression
- Calibration range 밖의 behavior

## Port extension과 새 calibration은 다르다

Port extension은 알려진 delay/loss를 phase reference에 적용하는 간단한 plane shift다. Complex fixture mismatch와 cross-coupling을 제거하려면 S2P de-embedding, AFR extraction 또는 TRL/LRM 같은 적절한 방법이 필요하다. 다음 챕터에서 이를 fixture model로 분리한다.

## Cause/Effect를 자기 말로 닫기

“Cable 끝에서 ECal을 수행했기 때문에 그 connector가 DUT reference plane이 되었다. 이후 sweep를 original 범위 안에서 줄이고 point를 바꾸자 correction terms가 새 grid에 보간되어 trace는 계속 표시되지만, cable 상태와 stimulus가 동일한지 verification standard로 다시 확인해야 한다.”

</LessonLayer>
