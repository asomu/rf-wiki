장비 목록은 capability 목록이 아니다. `N9020B가 있다`는 문장은 spectrum을 볼 수 있다는 출발점일 뿐이며, LTE EVM까지 유효하게 측정할 수 있다는 결론은 아니다. Model, option, firmware, measurement application, license, cable·coupler·attenuator와 calibration evidence가 한 묶음으로 확인돼야 한다.

<LessonLayer level="intuition" title="가능 여부를 장비 이름이 아니라 질문별로 판정하자">

## 세 상태는 편의 표시가 아니라 시험 진입 조건이다

<Definition term="READY">
현재 station manifest에 필요한 장비·option·accessory가 있고, 적용 범위를 덮는 calibration과 verification evidence가 유효한 상태다. 실제 DUT 측정 직전의 preflight는 별도로 통과해야 한다.
</Definition>

<Definition term="CONDITIONAL">
장비의 nominal capability는 있지만 option·application·license, bandwidth, residual, correction 또는 accessory 중 하나 이상을 실제 station에서 확인해야 하는 상태다. 확인 전 결과를 PASS/FAIL 근거로 쓰지 않는다.
</Definition>

<Definition term="BLOCKED">
현재 manifest가 질문에 필요한 관찰량을 만들지 못한다. 다른 숫자로 대체하거나 추정값을 실측처럼 쓰지 않고 필요한 장비·방법을 명시한다.
</Definition>

## Average, peak, PAPR와 damage level은 같은 축이 아니다

- **Average power**는 지정 aperture 동안 적분한 RF power다. PA thermal load와 long-term power budget에 중요하다.
- **Envelope peak**는 detector bandwidth와 sample record가 허용하는 시간 분해능 안의 최대값이다.
- **PAPR/CCDF**는 waveform sample 통계, oversampling, filtering과 record length에 의존한다.
- **Damage level**은 장비가 견디는 절대 경계이며 반복 운용 목표가 아니다.
- **Working level**은 linearity, uncertainty, headroom과 external protection을 포함해 station이 정한 더 보수적인 범위다.

U2061XA가 wideband average power를 읽을 수 있어도 최대 5 MHz peak path가 LTE 20 MHz envelope의 true peak와 CCDF를 완전히 보존한다고 결론 내리지 않는다. 반대로 N9020B의 160 MHz analysis bandwidth도 선택한 IQ sample rate, record, application과 residual이 맞아야 의미가 있다.

## Manifest 한 행에 들어갈 최소 증거

| 구분 | 기록할 값 | 판정을 막는 예 |
|---|---|---|
| Identity | Manufacturer, model, serial, firmware | Family는 같지만 다른 model |
| Hardware option | 506, 656, B1X 등 query-back | 주문서만 있고 장비 query 없음 |
| Application/license | 이름, version, license state | LTE EVM application 미확인 |
| Accessory | Coupler, pad, DC block, load, cable, cal kit | Power·frequency rating 미상 |
| Calibration | ID, plane, range, date, verification | Cable 이동 후 verification 없음 |
| Working envelope | Frequency, average/peak power, bandwidth | Damage limit만 복사 |
| Residual | Through EVM/ACLR, noise floor, drift | DUT 연결 후 처음 확인 |

필수 accessory는 “있을 것”으로 가정하지 않는다. Coupler 방향과 coupling factor, attenuator average/peak rating, DC block voltage·frequency range, 50 Ω load의 mismatch·power rating, cable loss·phase stability, cal kit definition과 torque tool 상태를 실제 asset ID로 연결한다.

## Capability 판정 순서

1. 측정하려는 **measurand**와 DUT reference plane을 한 문장으로 적는다.
2. 필요한 stimulus, acquisition bandwidth, dynamic range, timing과 correction을 적는다.
3. 각 요구를 station manifest의 장비·option·application·accessory에 매핑한다.
4. Missing evidence가 있으면 CONDITIONAL, 물리 capability가 없으면 BLOCKED로 둔다.
5. READY라도 station verification이 만료됐으면 다음 lesson에서 다시 막는다.

<MeasurementNote title="현재 pinned bench는 temperature, ET와 VSWR ruggedness를 자동으로 제공하지 않는다" kind="warning">
N6705C/N6752A readback을 DUT junction temperature나 완전 동시 V/I capture로 부르지 않는다. Fixture temperature는 별도 sensor가 실제로 있을 때만 optional metadata다. Tuner·mismatch source가 없는 상태에서 nominal 50 Ω S-parameter를 VSWR ruggedness 결과로 확대하지 않는다.
</MeasurementNote>

<LessonLayer level="theory" title="표준 적용 범위와 module 책임을 분리한다">

TS 36.101 V17.6.0 clause 5.5는 E-UTRA operating band를, clause 6은 완성 UE transmitter의 minimum requirement를 다룬다. TS 36.521-1 V17.7.0 clause 6은 해당 UE transmitter conformance 조건을 제공한다. 이 문서들이 개별 PAMiD의 gain·PAE·EVM allocation을 직접 정하는 것은 아니다.

이 경로의 대표 사례는 **Band 3 계열 1.7 GHz UE uplink, LTE 20 MHz FDD**다. 실제 EARFCN이나 고객 specification을 복제하지 않고, page에 제시되는 module target은 모두 명시적인 **가상 project allocation**이다. 따라서 capability 질문은 두 층으로 기록한다.

1. 표준 waveform·band·UE 조건을 station이 만들고 관찰할 수 있는가?
2. 가상 PAMiD allocation을 판정하기에 station uncertainty와 residual이 충분한가?

FDD duplexer path의 결과를 NR TDD TxM switch path로 옮기지 않는다. TDD edge timing, ET alignment와 switch transient는 후속 milestone에서 새로운 capability manifest로 다시 시작한다.
