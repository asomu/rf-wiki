Senior DVT 결론은 “PA 문제로 보임”이 아니다. 어느 조건에서 무엇이 fail했고, station과 measurement point가 유효했으며, 어떤 가설을 어떤 signature로 분리했고, 남은 불확실성이 다음 결정에 어떤 위험을 남기는지 한 페이지에서 추적할 수 있어야 한다. 이 capstone의 세 case는 서로 다른 DUT point 세 개가 아니라, **한 requalified multi-metric point에서 시작한 세 investigation thread**다.

<LessonLayer level="intuition" title="Evidence를 보기 전에 예상 signature를 먼저 고정하자">

## Blind diagnosis의 순서

1. 주어진 symptom과 유효성 evidence만 읽는다.
2. 가능한 source·path·DUT·analyzer 가설을 우선순위로 적는다.
3. 가장 정보량이 큰 다음 측정 하나를 고른다.
4. 각 가설이 맞다면 나타날 signature를 evidence 공개 전에 고정한다.
5. Evidence를 공개하고 지지·반증·중립으로 분류한다.
6. 가설 순위를 갱신하고 false-positive와 남은 uncertainty를 적는다.

<DvtLab labId="blind-fdd-capstone" progressId="dvt:fdd-dvt-conclusion" />

<Definition term="Confirmed">
대체 가설을 직접 분리하는 독립 evidence가 있고, 반복·correction·uncertainty와 capability가 결론을 지지한다. 교육 case 안에서만 사용하는 confidence이며 실제 failure analysis sign-off를 자동 대체하지 않는다.
</Definition>

<Definition term="Strongly indicated">
여러 evidence가 한 가설을 일관되게 지지하지만 직접 원인 측정 또는 중요한 대체 가설 제거가 남아 있다.
</Definition>

<Definition term="Unresolved">
Evidence가 서로 충돌하거나 station capability/uncertainty 때문에 후보 순위를 실질적으로 좁히지 못했다. 추측으로 PASS/FAIL 원인을 채우지 않고 다음 측정을 요구한다.
</Definition>

<LessonLayer level="bench" title="한 multi-metric point의 세 investigation thread를 같은 진단 계약으로 닫는다">

세 thread는 같은 point ID, waveform/checksum, corrected Pout, DUT mode, supply state와 acquisition group을 공유한다. 각 step은 source metric evidence와 별도 verification evidence를 연결하고, 마지막 decision은 그 thread에 연결된 원본에서 다시 계산한다. 독자가 화면의 evidence를 검토한 뒤 다른 fixture의 숫자로 결론을 받는 구조는 허용하지 않는다.

Conclusion의 `fnv1a32:` 값은 canonical payload `dvt-evidence-canonical-v1`에 계산한 **결정론적 교육용 비보안 체크섬**이다. 실수로 source record가 달라진 것을 재현 가능하게 찾는 장치일 뿐, 암호학적 digest나 tamper-proof 보안 통제로 해석하지 않는다.

## Case 1 · Gain·PAE suspected-fail history

Preliminary symptom은 fail처럼 보였지만 requalified source point의 최종 allocation disposition은 **PAE PASS**다. 이 case는 수정 전 query-back mismatch가 어떻게 거짓 fail 이력을 만들었는지 조사한다.

초기 후보는 path correction drift, generic gain-mode 적용 실패, supply CC와 thermal droop다. 가장 정보량이 큰 측정은 symptom에 따라 달라진다.

- Measured Pin/Pout correction을 known path에서 재검증하면 path drift와 DUT 변화가 갈린다.
- Control state query-back와 low-power gain을 비교하면 mode 적용 실패 후보를 좁힌다. 이 case의 mismatch는 **수정 전 선행 diagnostic observation**으로 보존되며, 최종 synchronized point는 correction 후 intended와 queried mode가 일치해야 VALID다.
- VDD/IDD, CV/CC와 시간에 따른 gain을 함께 보면 supply limit·droop 후보를 분리한다.
- Fixture temperature sensor가 실제로 없으면 thermal mechanism을 직접 확인했다고 쓰지 않는다.

PAE fail은 PSU 숫자만으로 결론 내리지 않는다. 이 교육 fixture의 Pin, Pout, VDD, IDD는 한 acquisition group의 독립 record다. 공통 trigger·DUT state와 허용 trigger repeatability를 만족해야 같은 valid point로 결합할 수 있으며, 서로 겹친 aperture라고 표현하지 않는다.

## Case 2 · EVM·ACLR anomaly investigation

Preliminary symptom은 EVM·ACLR fail 의심이었고, requalified point의 최종 ACLR disposition은 uncertainty interval이 limit에 겹치는 **INCONCLUSIVE**다. DUT fail로 확정하지 않는다.

초기 후보는 source residual, PA peak compression·memory, analyzer ACLR input-range artifact와 EVM demodulation artifact다.

- Passive through의 동일 waveform residual이 나쁘면 DUT 이전 문제를 우선한다.
- Analyzer attenuation step의 현재 evidence는 corrected ACLR delta·repeatability·uncertainty·mixer/noise headroom만 검증한다. 이 step이 attenuation-invariant이면 ACLR input-range artifact 후보만 낮춘다.
- N9020B level ledger는 strongest connector signal과 connector total을 먼저 기록하고 `mixer total = connector total − input attenuation`으로 계산한다. Mixer headroom은 station-verified operating boundary와 비교하며 0 dBm reference level은 display/setup record일 뿐 headroom 경계나 vendor accuracy claim이 아니다. Dominant off-screen TX carrier가 strongest connector signal 자체라면 별도 carrier로 다시 합산하지 않는다.
- Analyzer headroom, station-qualified negative-dBm mixer boundary, IF/ADC 또는 attenuation-step residual은 서로 다른 typed evidence ID로 등록한다. ACLR·EVM·analyzer Pout conclusion source는 세 record를 모두 연결해야 하며, limit/residual ID가 point·asset·query-back·timestamp·applicability와 exact하게 맞지 않으면 결론을 만들지 않는다.
- EVM demodulation artifact를 낮추려면 별도의 demod attenuation step, corrected EVM delta, application/license, reference/equalization/normalization, residual과 EVM uncertainty evidence가 필요하다.
- Pout back-off에서 EVM·ACLR이 함께 회복되고 AM-AM/AM-PM signature가 있으면 PA 비선형 후보가 강해진다.
- Tone spacing, record 시작/끝과 upper/lower regrowth 차이는 memory 후보를 좁힌다.

EVM application/license, reference waveform, equalization, normalization과 residual이 확인되지 않으면 EVM evidence는 CONDITIONAL이다. ACLR과 spectrum evidence만으로 같은 결론을 가장하지 않는다.

## Case 3 · Tx noise·Rx desense risk

초기 후보는 PA RX-band noise, duplexer/isolation 부족, bench leakage와 analyzer floor다. 현재 pinned bench는 receiver sensitivity나 BLER를 직접 측정하지 않으므로 실제 desense 값을 산출하지 않는다.

- PA Off/On과 source terminated baseline으로 analyzer floor·bench leakage를 분리한다.
- DUT-plane RX-band noise와 independently verified duplexer/isolation evidence를 budget에 넣되 둘을 같은 source라고 쓰지 않는다. `tx-noise`는 risk를 지지하는 metric evidence이고, isolation 판정의 실제 measurement source는 별도 isolation evidence ID다.
- Analyzer preamp/attenuation, RBW/integration bandwidth와 correction을 고정한다.
- 실제 RX chain, wanted signal, receiver gain state와 BLER evidence가 없다는 사실을 남긴다.

결과 제목은 **desense risk budget**이다. `actual Rx desense = x dB` 또는 `receiver sensitivity fail confirmed`라고 쓰지 않는다.

<MeasurementNote title="한 번에 여러 설정을 바꾸면 evidence의 정보량이 사라진다" kind="warning">
Waveform, Pin, gain mode, attenuation과 bias를 동시에 바꾸지 않는다. 다음 측정은 우선 가설 두 개 이상이 서로 다른 signature를 내도록 설계하고, 바뀐 control과 결과를 ledger에 남긴다.
</MeasurementNote>

## 필수 report 구조

| 항목 | 기록 내용 |
|---|---|
| Scope | LTE FDD Band 3 계열 교육 profile, waveform·frequency·power·module state |
| Station | Manifest version, READY/CONDITIONAL/BLOCKED, calibration/verification ID |
| Symptom | Metric, reference plane, native sign, limit direction과 가상 allocation |
| Validity | VALID/INVALID/INCONCLUSIVE와 instrument status·cleanup |
| Decision | Measurement interval과 PASS/FAIL/INCONCLUSIVE rule |
| Hypotheses | 초기 순위, 선택한 분리 측정과 고정한 expected signature |
| Evidence | 지지·반증·중립, correction와 uncertainty |
| Conclusion | Confirmed/Strongly indicated/Unresolved confidence |
| Residual risk | False-positive, missing capability, 다음 측정·owner |

결론 문장은 다음 형식을 따른다.

> **무엇을 관찰했는가 → 어떤 독립 evidence가 어느 후보를 지지/반증하는가 → 현재 confidence는 무엇인가 → 아직 무엇을 말할 수 없는가 → 다음 engineering action은 무엇인가**

예를 들어 `ACLR fail confirmed`보다 `Qualified through residual과 attenuation-step invariance가 source/analyzer 후보를 낮췄고, Pout back-off에서 AM-AM·ACLR가 함께 회복돼 PA compression이 strongly indicated되지만 thermal state 직접 측정은 남아 있다`가 더 방어 가능하다.

TS 36.101과 TS 36.521-1은 완성 UE requirement/conformance의 조건을 추적하는 근거다. 이 capstone의 target과 case data는 명시적인 가상 project allocation이며 실제 PAMiD vendor register, 고객 데이터 또는 certification verdict를 포함하지 않는다.
