RF bench에서 “power가 30 dBm이다”라는 문장은 아직 불완전하다. source available power인지, DUT plane의 forward power인지, reflected를 뺀 accepted power인지, coupler sample에 coupling correction을 더한 추정값인지 적어야 한다. 이 단원은 **위치, 방향, 분모** 세 가지를 모든 power label에 붙인다.

<LessonLayer level="intuition" title="한 전송선에 왜 forward와 reverse power가 동시에 있을까?">

## reference plane을 통과하는 두 화살표

PA에서 load로 가는 incident/forward wave를 `a`, load에서 되돌아오는 reflected/reverse wave를 `b`라고 하자. 같은 connector plane을 서로 반대 방향으로 통과한다.

- Forward power가 10 W이고 reflected power가 1 W라면 DUT가 그 plane 안쪽으로 받아들이는 net power는 9 W다.
- reflected 1 W가 어디에서 최종 소모되는지는 source match, isolator, cable loss에 따라 달라진다.
- 일반적인 scalar power meter 하나는 두 방향을 분리하지 못한다. directional coupler 또는 reflectometer가 필요하다.

<Definition term="accepted power">
DUT input reference plane에서 incident power에서 reflected power를 뺀 net power다. normalized real-reference power-wave convention에서는 `Paccepted = |a|² − |b|²`다.
</Definition>

<Definition term="available power">
source 또는 2-port가 conjugate-matched load에 줄 수 있는 최대 power다. 현재 load에 실제로 전달된 power와 다를 수 있다.
</Definition>

<Definition term="delivered power">
문맥 의존 용어다. 이 Wiki에서는 반드시 대상과 plane을 붙여 `power delivered to load`, `DUT accepted input power`처럼 쓴다. 단독으로 “delivery power”라고 하지 않는다.
</Definition>

## Directional coupler는 한 방향의 작은 복사본을 만든다

forward 방향 port naming을 다음처럼 고정하자.

`Port 1 Input → Port 2 Through`

`Port 3 Coupled ← forward sample`

`Port 4 Isolated ← ideally no forward sample`

실제 물리 package의 번호는 제조사마다 다르므로 datasheet 화살표를 먼저 확인한다. 여기서는 `1=input, 2=through, 3=forward-coupled, 4=forward-isolated` convention을 사용한다.

- **Coupling 20 dB:** input power의 1%, voltage-wave magnitude의 10%가 port 3에 나타난다.
- **Isolation 45 dB:** forward input에 대해 port 4 leakage가 input보다 45 dB 낮다.
- **Directivity 25 dB:** wanted coupled sample이 unwanted isolated leakage보다 25 dB 크다. `45 − 20 = 25 dB`다.

## insertion, coupling, isolation은 같은 ‘loss’가 아니다

| 이름 | 비교하는 port/power | 20 dB coupler의 예 |
|---|---|---|
| Coupling | input 1 → coupled 3 | `C = 20 dB`, P3=1% P1 |
| Main-line insertion loss | input 1 → through 2 | ideal division만이면 약 0.044 dB 이상 |
| Isolation | input 1 → isolated 4 | `I = 45 dB` |
| Directivity | wanted coupled 3 → leakage 4 | `D = 25 dB` |
| Excess loss | input 대비 through+coupled 합의 손실 | ideal lossless면 0 dB |

20 dB coupling이라고 through path가 20 dB 손실되는 것이 아니다. input의 1%만 coupled path로 빠지므로 이상적인 through power는 99%, coupling 자체가 만드는 main-line loss는 약 0.044 dB다. 여기에 conductor/dielectric loss와 mismatch가 더해진다.

## 다른 multiport 소자의 화살표

- **Switch:** selected path의 insertion loss와 unselected path로 새는 isolation을 각 port pair로 쓴다.
- **2-way splitter:** input power가 두 output으로 나뉘어 ideal 각 path는 -3.01 dB다. 실제 insertion은 division loss+excess loss다. output-to-output isolation은 별도다.
- **Combiner:** reciprocal passive splitter를 반대로 쓸 수 있지만 두 input의 phase/amplitude가 맞지 않으면 isolation resistor에 power가 소모된다.
- **Isolator:** forward path는 낮은 insertion loss, reverse path는 높은 isolation을 목표로 하며 reverse power를 내부 termination에 흡수한다.
- **Circulator:** 이상적으로 `1→2`, `2→3`, `3→1` 순환한다. 어떤 port를 termination하면 isolator처럼 쓸 수 있다.

## 먼저 port map을 그린다

datasheet의 방향 화살표와 connector label을 사진 또는 bench note에 고정한다. 이 단원의 convention과 실제 DUT 번호가 다르면 S-parameter mapping table을 만든다.

| Coupler 역할 | 실제 DUT port | VNA 연결 | 측정 |
|---|---:|---:|---|
| Input | 1 | VNA 1 | excitation |
| Through | 2 | VNA 2 | `S21` main line |
| Forward coupled | 3 | VNA 3 | `S31` coupling |
| Forward isolated | 4 | VNA 4 | `S41` isolation |

4-port VNA가 없으면 pair를 바꾸어 2-port 측정할 수 있지만 **측정하지 않는 모든 coupler port를 좋은 50 Ω load로 termination**해야 한다. open unused port는 isolation과 directivity 결과를 망친다.

## Calibration과 dynamic range

1. coupler 동작 대역보다 넓게 start/stop을 잡는다.
2. expected isolation보다 충분한 receiver dynamic range를 확보한다.
3. source power가 DUT power rating과 VNA receiver limit을 넘지 않게 한다.
4. 4-port ECal/SOLT/unknown-thru를 connector plane까지 수행한다.
5. low-loss thru와 matched load로 residual tracking/directivity를 검증한다.
6. IFBW와 averaging은 deep isolation trace의 random noise를 줄이되 drift 시간을 확인한다.

## Trace를 같은 방향에서 계산한다

Forward excitation port 1 기준:

- `Coupling C = −S31(dB magnitude)`
- `Main-line IL = −S21(dB magnitude)`
- `Isolation I = −S41(dB magnitude)`
- `Directivity D = I − C = S31(dB) − S41(dB)`

예를 들어 marker가 `S31=-20.2 dB`, `S41=-46.0 dB`면 `C=20.2 dB`, `I=46.0 dB`, `D=25.8 dB`다. 음수 S-parameter trace와 양수 loss specification을 한 표에 섞지 않는다.

Reverse excitation port 2에서는 port 4가 reverse-coupled가 되고 port 3이 reverse-isolated인 대칭 구조가 흔하다. 따라서 `S42`와 `S32`를 본다. 비대칭 coupler는 datasheet 정의를 따른다.

## Coupler로 PA forward/reflected power를 읽는 흐름

`PA → coupler input → coupler through → load`

- forward-coupled sample은 attenuator/power sensor 또는 analyzer에 연결한다.
- reverse-coupled sample은 반대 방향 port에서 읽는다.
- 각 sample readout에 frequency-dependent coupling calibration을 더해 main-line wave power를 추정한다.
- sample path cable/attenuator loss와 sensor calibration factor를 더한다.
- forward와 reverse sample의 reference plane을 같은 DUT plane으로 de-embed한다.

예: forward sample `+9.6 dBm`, calibrated coupling `20.3 dB`, sample cable loss `0.4 dB`라면 main-line forward 추정은 `9.6 + 20.3 + 0.4 = 30.3 dBm`이다. 부호는 “sample path에서 잃은 양을 main line으로 되돌려 더한다”로 sanity check한다.

## finite directivity가 reflection 측정을 제한한다

forward sample에 reverse leakage가, reverse sample에 forward leakage가 섞인다. directivity 30 dB coupler로 return loss 30 dB load를 재면 wanted reverse wave와 leakage가 비슷한 크기다. 두 complex vector의 phase에 따라 결과가 과대 또는 과소가 될 수 있어 단순히 “30 dB까지 정확”하지 않다.

<MeasurementNote title="directivity는 isolation과 coupling을 함께 봐야 한다">
Isolation 50 dB만 보고 좋은 coupler라고 말할 수 없다. Coupling이 40 dB라면 directivity는 10 dB뿐이다. 방향성 측정의 유용한 분리도는 `isolation − coupling`이며 frequency, connector match, termination에 따라 달라진다.
</MeasurementNote>

## mismatch와 calibration error가 power budget에 들어오는 경로

- PA output mismatch와 coupler input match 사이의 multiple reflection
- coupler through output match와 load mismatch
- coupled port termination mismatch가 main line 및 directivity에 미치는 영향
- sample cable loss와 phase drift
- coupling flatness와 temperature coefficient
- sensor linearity/zero/cal factor 또는 analyzer amplitude uncertainty
- modulated signal의 crest factor와 sensor detector bandwidth

CW coupling calibration을 wideband OFDM peak 또는 average power에 그대로 적용할 때 sensor bandwidth와 coupler frequency response를 확인한다.

## insertion/isolation을 장치별로 읽는 예

### RF switch

Port 1→2 selected에서 `S21=-0.8 dB`면 insertion loss 0.8 dB다. Port 1→3 unselected에서 `S31=-62 dB`면 isolation 62 dB다. switch state와 control voltage를 반드시 기록한다.

### 2-way splitter

각 output이 `S21=-3.4 dB`, `S31=-3.5 dB`면 ideal division 3.01 dB를 뺀 추가 path loss와 amplitude imbalance를 본다. `S23`는 output isolation이다.

### Isolator/circulator

Isolator의 forward `S21=-0.5 dB`는 insertion loss 0.5 dB, reverse `S12=-25 dB`는 isolation 25 dB다. circulator는 모든 six transmission terms를 port circulation 방향과 함께 읽는다.

</LessonLayer>

<LessonLayer level="theory" title="power-wave와 coupler 식의 부호를 고정하자">

<FormulaDisclosure title="normalized incident/reflected/accepted power" formula="Pinc = |a|²,   Pref = |b|²,   Paccepted = |a|²−|b|²">
real positive reference impedance와 RMS-equivalent normalized power-wave convention이다. voltage-wave 또는 complex reference impedance에서는 정의를 명시해야 한다. `Γ=b/a`이면 `Paccepted=Pinc(1−|Γ|²)`다.
</FormulaDisclosure>

<FormulaDisclosure title="coupling, main-line loss, isolation" formula="C = −20log₁₀|S₃₁|,   IL = −20log₁₀|S₂₁|,   I = −20log₁₀|S₄₁|">
matched ports와 port 1 forward excitation convention이다. power ratio로 쓰면 각각 `−10log(Pout/Pin)`과 같다. dB magnitude trace는 음수, specification loss는 양수로 표기했다.
</FormulaDisclosure>

<FormulaDisclosure title="directivity" formula="D = I−C = 20log₁₀(|S₃₁|/|S₄₁|)">
wanted coupled wave가 unwanted leakage보다 몇 dB 큰지 나타낸다. directivity는 방향 분리 능력이고 reverse isolation 자체와 같지 않다.
</FormulaDisclosure>

<FormulaDisclosure title="coupling에 의한 이상적 main-line division loss" formula="Ldivision = −10log₁₀(1−10^(−C/10))">
`C=20 dB`면 coupled power fraction은 0.01, ideal through fraction은 0.99, division loss는 약 0.0436 dB다. 실제 main-line insertion loss는 여기에 dissipative loss와 mismatch 효과가 더해진다.
</FormulaDisclosure>

<FormulaDisclosure title="coupler excess loss" formula="Lexcess = −10log₁₀((Pthrough+Pcoupled)/Pinput)">
이 Wiki가 고정한 useful-port convention이다. isolated leakage `Pisolated`는 분자에 넣지 않지만 passivity 확인에서는 별도 output으로 더해 `Pthrough+Pcoupled+Pisolated ≤ Pinput`인지 검사한다. 따라서 finite isolation이면 정확히 0 dB excess와 동시에 둘 수 없다. lossless·infinite-directivity ideal coupler에서만 through와 coupled power의 합이 input과 같아 excess loss 0 dB다.
</FormulaDisclosure>

## 세 가지 gain의 분모

<FormulaDisclosure title="transducer, operating, available power gain" formula="GT = PL/Pavs,   GP = PL/Pin,   GA = Pavn/Pavs">
`Pavs`는 source available power, `Pin`은 network가 accepted한 input power, `PL`은 load에 delivered된 power, `Pavn`은 network가 output에서 available하게 만들 수 있는 power다. source/load mismatch가 있으면 세 gain은 다르다.
</FormulaDisclosure>

## 수치 예: 10 W forward, VSWR 2:1 load

`|Γ|=(2−1)/(2+1)=1/3`이므로 reflected power는 `10 W × 1/9 = 1.111 W`, accepted power는 `8.889 W`다. forward sample이나 PA directional power meter가 10 W를 표시했다고 load accepted power가 10 W인 것은 아니다.

만약 coupler directivity가 충분하지 않으면 reverse sample은 1.111 W의 실제 반사와 forward leakage의 complex 합이다. coupling calibration만으로 directivity error가 제거되지는 않는다.

## 이 단원의 convention

- coupler port: 1 input, 2 through, 3 forward-coupled, 4 forward-isolated
- S-parameter dB magnitude는 음수, loss/directivity spec은 양수
- main-line insertion loss와 coupling loss를 구분
- accepted power는 동일 reference plane의 incident minus reflected
- “delivered”에는 source와 destination plane을 붙임
- 모든 unused multiport는 지정 impedance로 termination
- CW calibration을 modulation에 적용할 때 detector bandwidth/crest factor를 확인
